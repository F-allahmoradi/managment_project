API نسخه ۱

وب و موبایل هر دو به همین سرویس وصل می‌شوند. آدرس پایه در توسعه http://127.0.0.1:8080 است.

ورود

POST /api/v1/auth/login
{"username":"...", "password":"..."}

پاسخ فیلد access_token دارد. بعد از آن هر درخواست این هدر را می‌خواهد:

Authorization: Bearer توکن

ثبت‌نام: POST /api/v1/auth/register با نام، نام خانوادگی، نام کاربری و رمز. اگر هنوز کاربری نباشد، همان حساب مدیر کل می‌شود. پاسخ مثل ورود توکن دارد.

خروج: POST /api/v1/auth/logout. کاربر جاری: GET /api/v1/auth/me. فیلد roles نام نقش‌های فعال است.

دو شکل صدا زدن

مسیرهای آمادهٔ داشبورد، مثل GET /api/v1/projects و GET /api/v1/meetings.

بقیهٔ ابزارها: POST /api/v1/{domain}/tools/{tool} با بدنهٔ JSON همان آرگومان‌ها. ابزار خواندنی را می‌شود با GET و کوئری هم صدا زد.

فهرست کامل: GET /api/v1/catalog. سند ماشین‌خوان: GET /api/v1/openapi.json.

خطا

بدنه همیشه status و در خطا error_code و message دارد. کد HTTP جداگانه است: ۴۰۱ بدون توکن، ۴۰۳ بدون مجوز، ۴۰۴ پیدا نشد، ۴۲۲ ورودی نامعتبر.
